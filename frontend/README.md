# Maison Atelier - Frontend

Premium user interface for the Maison Atelier e-commerce platform. Built with React and Vite, featuring a completely custom authentication flow, glassmorphism design, and state-of-the-art UI components.

## Tech Stack
- **Framework**: React + Vite
- **Styling**: Tailwind CSS
- **State Management**: Context API
- **Routing**: React Router DOM

## Key Features
- **Custom Authentication UI**: Sleek login, registration, and OTP verification screens integrated directly with the custom Node.js backend (No third-party auth).
- **Responsive Design**: Flawless experience across mobile, tablet, and desktop.
- **Premium Aesthetics**: High-end fashion storefront feel with smooth micro-animations and curated typography.
- **Secure Handling**: Safe management of JWT tokens and seamless protected routing.

## Getting Started

1. Set up the `.env` file:
   ```bash
   cp .env.example .env
   # Ensure VITE_API_BASE_URL points to your backend (e.g., http://localhost:4000)
   ```

2. Install dependencies and run:
   ```bash
   npm install
   npm run dev
   ```
